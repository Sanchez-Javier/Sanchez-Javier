**Descripción:** Proyecto de pruebas de una aplicación web para personalizar y crear kits de productos.

**Actividades realizadas:**

- Diseñé y ejecuté **104 casos de prueba manuales** para validar los requisitos de la API.
- Documenté resultados, datos de prueba y defectos encontrados.

- Desarrollé **9 pruebas automatizadas con Python y Pytest** para validar la creación de kits.
- Verifiqué respuestas HTTP exitosas (201) y de error (400).

**Tecnologías:** Postman, Python, Pytest, JSON y JIRA.

### 🔹 Urban Routes | Automatización web con POM

**Descripción:** Proyecto de automatización de pruebas de una plataforma web para solicitar servicios de transporte.
